# Whole Robot Assembly

`source/assembled-robot.f3z` is the editable Autodesk Fusion archive for the
partial whole-robot assembly. It brings the major robot subsystems together in
one model, but it is not yet a complete or fabrication-ready representation of
every installed component.

This is a living hardware source model. It will continue to be maintained after
the thesis submission as the assembled robot and its subsystem designs evolve.
Update this archive deliberately and describe material assembly changes in the
commit message.

The F3Z archive is stored with Git LFS because native CAD revisions are large
binary files. Install Git LFS before cloning or pulling this model.
